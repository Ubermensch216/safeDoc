# AI 탐지 시험 문서 — 정답지

`npm run testdocs` 로 생성한다. (`scripts/createAiTestDocuments.mjs`)

**여기 나오는 모든 이름·번호·주소는 시험용 가상 정보다. 실제 개인정보가 아니다.**

## 목적

규칙 기반 탐지가 **원리적으로 놓치는** 사례를 의도적으로 심어 두었다.
지원하는 모든 파일 형식(`.txt`, `.csv`, `.docx`, `.xlsx`, `.hwpx`, `.pdf`)에 대해
형식별 중복 없이 각 1종씩, 3~4쪽 이상 분량의 문서를 `test/documents/` 에 제공한다.

## 파일 목록 (`test/documents/`)

| 파일명 | 형식 | 분량 | 주요 검증 포인트 |
|---|---|---|---|
| `01_민원상담_및_공지모음.txt` | TXT | 약 4쪽 | 문맥형(필드명 없음), 변형표기(공백/한글숫자/`[at]`), 오탐 함정 통합 |
| `02_외부인력_및_협력사명부.csv` | CSV | 125행 (3쪽+) | 비정형 헤더(`작업자`, `연결처`), 외국인 성명, 한글 숫자 전화번호 |
| `03_개인정보_실태점검_회의록.docx` | DOCX | 4쪽 | 분리된 `<w:t>` 런 결합, 표(`w:tbl`), 머리글(`header1.xml`) |
| `04_근태_및_인사기록.xlsx` | XLSX | 2시트 180여 행 (3쪽+) | 공유 문자열, 인라인 문자열, 숫자 서식 셀(`1098765432`, `9001011234567`) |
| `05_업무협조_및_점검보고서.hwpx` | HWPX | 4쪽 | 본문 문단 + 다수의 표(`<hp:tbl>`) + 분리 런(`<hp:t>`) |
| `06_개인정보_처리현황_보고서.pdf` | PDF | 4쪽 | 한글 텍스트 레이어, 표 레이아웃, 불투명 가림 + 토큰 치환 |

## 사용법

```bash
npm run testdocs     # test/documents/ 에 6종 문서 생성
deploy/start.bat     # 앱 실행 후 문서를 끌어놓는다
```

비교하려면 **설정 탭 → AI 탐지 사용**을 껐다 켜면서 같은 문서를 두 번 돌린다.
