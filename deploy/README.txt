safeDoc — 개인정보 비식별화 프로그램 (폐쇄망 설치 안내)
==========================================================

이 폴더의 구성
--------------
  index.html    프로그램 본체 (단일 HTML)
  start.bat     실행 파일 — 이것을 더블클릭하십시오
  serve.ps1     로컬 서버 스크립트 (start.bat이 자동으로 실행)
  README.txt    이 문서


빠른 시작
---------
  1. start.bat 을 더블클릭합니다.
  2. 브라우저가 자동으로 열립니다. (http://localhost:8080)
  3. 문서를 끌어놓아 비식별 처리를 시작합니다.
  4. 사용이 끝나면 검은 창에서 Ctrl+C 를 누르거나 창을 닫습니다.

  AI 탐지 없이 규칙 기반으로만 쓸 경우 이 상태로 충분합니다.


AI 탐지를 사용하려면
--------------------
문서의 맥락을 판단해 규칙이 놓치는 개인정보(특히 성명)를 추가로 찾아냅니다.
아래 두 가지를 준비하십시오.

  1) Ollama 설치
     - 폐쇄망에서는 설치 파일을 미리 반입해야 합니다.
     - 설치 후 Ollama가 백그라운드에서 실행 중이어야 합니다.

  2) 모델 준비
     명령 프롬프트에서:

         ollama pull gemma4:e2b

     폐쇄망이라 내려받을 수 없으면, 인터넷이 되는 PC에서 받은 뒤
     모델 폴더를 그대로 옮기십시오.
     기본 경로: %USERPROFILE%\.ollama\models

  준비가 끝나면 start.bat 을 다시 실행합니다.
  검은 창에 "AI 탐지 사용 가능"이라고 표시되면 정상입니다.


중요: 왜 그냥 index.html 을 열면 안 되는가
-------------------------------------------
index.html 을 브라우저로 직접 열면(file:// 주소) AI 탐지가 동작하지 않습니다.
Ollama가 file:// 출처의 요청을 보안상 거부하기 때문입니다.

start.bat 은 이 문제를 피하려고 프로그램을 http://localhost 주소로
바꿔서 열어줍니다. 외부로 나가는 통신은 아닙니다.


개인정보 보호
-------------
  - 문서와 개인정보는 이 PC를 벗어나지 않습니다.
  - 네트워크 통신은 이 PC 안의 AI 엔진(localhost:11434) 하나로 제한됩니다.
    프로그램의 보안 정책(CSP)이 그 외 모든 통신을 차단합니다.
  - 대응표 파일에는 개인정보 원문이 그대로 들어갑니다.
    결과 파일과 분리하여 안전한 곳에 보관하십시오.
  - 업로드한 원본 파일은 변경되지 않습니다.


문제 해결
---------
  "실행할 수 없습니다" / 정책 오류
      start.bat 이 이미 우회 옵션을 씁니다. 그래도 막히면
      관리자에게 PowerShell 실행 정책 확인을 요청하십시오.

  포트가 사용 중
      8080부터 8089까지 자동으로 비어 있는 포트를 찾습니다.
      직접 지정하려면 명령 프롬프트에서:
          powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 9000

  "Ollama에 연결할 수 없습니다"
      Ollama가 실행 중인지 확인하십시오.
      AI 없이도 규칙 기반 탐지는 정상 동작합니다.

  브라우저가 자동으로 열리지 않음
      검은 창에 표시된 주소를 직접 입력하십시오.


지원 문서 형식
--------------
  TXT, CSV, XLSX, DOCX, HWPX, 텍스트 PDF   (최대 20MB)

  지원하지 않음: 구형 HWP/DOC/XLS, 암호·DRM 문서,
                 스캔 이미지 PDF, 실행파일, 압축파일
